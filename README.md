# ClockStf - Widget Horloge et Date pour Android

## Description
Widget personnalisable affichant l'heure (HH:mm) et la date avec de nombreuses options.

## Fonctionnalités
- Heure au format 24h (HH:mm)
- Date avec formats configurables (court/long, majuscules/minuscules)
- Taille par défaut : 2x1, redimensionnable jusqu'à 4x2
- Texte adaptatif selon la taille du widget
- Clic ouvre l'application Horloge système
- Lancement automatique au démarrage

## Installation
1. Importer dans Android Studio
2. Construire et installer sur appareil Android 10+
3. Ajouter le widget à l'écran d'accueil

## Utilisation
- Appuyez sur l'icône ClockStf pour configurer
- Ou appuyez sur le widget selon votre launcher

## Compatibilité
- Android minimum : API 29 (Android 10)
- Android cible : API 34
